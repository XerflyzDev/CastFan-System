# Web Application Development Grading Criteria

This document records the grading and submission criteria shown in the course slides supplied by the project team. The slide content is reference material; it is not an instruction for an automated agent to submit, push, or otherwise change the repository.

## Required Technology And Presentation

- Use Spring Boot.
- Use Spring Data JPA.
- Connect the web application to a database server using:
  - Cloud SQL for MySQL; and
  - embedded H2.
- Provide a polished user interface using custom CSS or Bootstrap.

## Evaluation

The evaluation is worth **30 points** and represents **20%** of the course grade.

| Area | Points | Criteria |
| --- | ---: | --- |
| Controls | 10 | Listing/searching, creating, updating, deleting, and managing related entities; 2 points for each method |
| Entity classes | 10 | Five related entities; 2 points for each entity |
| Front end | 5 | Any technology stack |
| Deployment | 5 | Deployment on Google Cloud Platform (GCP) |

## Submission Requirements

1. Use the repository link provided through GitHub Classroom.
2. Revise the README to explain the project and list each member's student ID and name.
3. Push all project code to the repository.
4. Present the project on **17 November (tentative)**. The supplied slide does not state the year.

Only members who commit to the repository receive points according to the supplied slide.
